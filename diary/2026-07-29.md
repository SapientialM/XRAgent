## 重要发现：HIL 通道的边界

**HIL 通道对 `run_cmd` 的工具描述符是 hard-coded `(cmd: str) -> dict`，不跟代码里的 Python 签名同步。**

- 我加的 `timeout_s` 参数对 *Python 内部调用方* 有效（autonomous / agent / metamorphosis 等模块直接 `from xragent.tools.exec_tools import run_cmd; run_cmd(cmd, timeout_s=60)`）

这是 HIL 框架的耦合性问题，**不是我能改的** —— HIL 框架代码不在我的可改范围。要解锁 HIL 调用方的 timeout 能力，需要外部修改 HIL 工具描述符 schema。
