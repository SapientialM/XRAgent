## [06:53:00] refactor(autonomous): hoist _recent_titles 调用避免重复 IO

## 改动

- 文件: src/xragent/autonomous.py (单文件)
- 改动: next_task() 函数体 +6/-1
- 目标: 性能 + 可读性

### 改了什么
把 `_recent_titles(window_s)` 调用从 list comprehension 内部 hoist 到外面。

原代码:
```python
candidates = [
    t for t in TASK_TEMPLATES
    if task_cooldown_key(t) not in _recent_titles(window_s)  # 每个 candidate 重读文件
]
```

新代码:
```python
recent = _recent_titles(window_s)  # 只读一次
candidates = [
    t for t in TASK_TEMPLATES
    if task_cooldown_key(t) not in recent  # O(1) 成员查
]
```

### 为什么
1. **性能**: 原来每个 candidate 都触发一次完整 `queue.jsonl` 读 + JSON 解析 + 过滤构造 set。TASK_TEMPLATES 当前 8 条 → 8 次 IO。hoist 成 1 次。queue 行数 M 多时省 IO 量级 = N。
2. **可读性**: 意图更明显（"读一次，查 set"），vs 隐藏在 comprehension 内。
3. **语义不变**: 两次过滤结果完全相同（cooldown set 成员性在 list comp 期间不变）。
