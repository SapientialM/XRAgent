2. `tests/test_memory.py` 加 7 个测试

## 设计要点
- **字段位置**：priority 末尾 + 默认 0，老代码 positional 构造 Fact 不破坏
- **NOT NULL DEFAULT 0** vs nullable：选 NOT NULL 让 priority=0 含义明确（"未标重要级"），避免 NULL 在 ORDER BY DESC 里被 SQLite 实现定义为最小（行为不可预期）
- **min_priority 默认 1**：让默认召回"只看显式标过重要级的 fact"，避免海量 history 涌入；`recall_high_priority(k=N, min_priority=0)` 仍可拿全
- **复合索引** `(category, priority DESC, ts DESC)`：
  - WHERE category=? + ORDER BY priority DESC, ts DESC 走 index seek + 自然顺序, 零额外排序
  - 无 category 时退化到 priority 上的 range scan，仍优于全表
  - 不能复用 idx_facts_category_ts (priority 永远在 ts 前但 priority DESC vs ts DESC 排序不同)
- **migration 老行回填**：SQLite 自 3.31.0 起 ALTER ADD COLUMN ... DEFAULT 会回填老行；显式 UPDATE 是兼容老版本保险, 1 行 SQL 代价低
- **NULL 安全**：recall_high_priority WHERE priority >= ? 中 NULL >= ? 为 NULL 不匹配, 老 ALTER 失败的极端情况下也不召回 garbage

决定重试 / 放弃 / 报警,不能沉默卡住。

### 设计要点
- `DEFAULT_PUSH_TIMEOUT_S = 30`,与 `exec_tools.DEFAULT_TIMEOUT_S` 对齐(单一来源
  意图,但未直接 import,避免循环 import 风险;test_default_push_timeout_constant
  锁两者相等 → 漂移时立刻 fail)
- `_resolve_timeout(value, default)` 纯函数边界:
  * None / 0 / 负数 / 非数值 (str/list/dict) / bool → default (拒绝 bool 是因
    为它是 int 子类,语义上是 True/False 不是数字;否则 True→1s timeout)
  * 正 int / 正 float → int(value) 截断
- `_fail(msg, /, **extras)` 字典工厂:
  * msg 是 positional-only (def 里 `msg: str, /`),防止 LLM 误用 kw 传
  * extras 显式传入才出现 → 成功路径字典键集合恒为 {ok, msg},失败路径
    timed_out=True 时多一个键。锁住 LLM 解析键集合不漂移
- git_push 三种失败路径:
  1. TimeoutExpired → `{"ok": False, "msg": "超时（>{t}s）", "timed_out": True}`
  2. FileNotFoundError → `{"ok": False, "msg": "FileNotFoundError: ..."}`
  3. OSError 子类 (PermissionError/ConnectionError/...) → `{"ok": False,
     "msg": "<子类名>: ..."}`  (用子类名而非 OSError 基类,因为子类名 + errno
     更具体,LLM 拿到能直接用)
