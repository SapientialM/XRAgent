## 三、风险点 / 改进候选 (留给 v0.4+)

### A. `core/backend.py` 里的 freezegun

- `MockBackend.retry` 测试用 `@freeze_time`, freezegun 是软依赖 (测试自己 try/except 跳过)
- 不是 v0.3.1 主线; 不阻塞

### B. `memory/manager.py` 的 5.8 召回

- `recall_lru(active_only=True)` 默认只召回未归档; 老行 `last_accessed_ts=0.0` 永远排最前
- 没有 LRU 的"自动驱逐"机制, 只是查询辅助 (适合做"找最久没看的记忆"复盘)
- v0.4 想做"内存压力下自动淘汰冷 fact"需要额外策略层

### C. side_git 的 `subprocess` import

- 显式保留: `tests/test_git_tools.py` 的 monkeypatch 拦截依赖模块级 `subprocess.run`
- 如果未来想彻底去掉, 测试也得改; 短期保持现状

### D. main.py 的 input queue 复杂度

- `cmd_interactive` 用 `queue.Queue` + `input_queue.get(timeout=1.0)`, 1s poll
- HTTP 模式 (`with_http=True`) 关掉 stdin reader, 全靠 HTTP 喂消息
- 没有 backpressure; 但 autonomous 模式已经够用

### E. ROADMAP.md 当前状态

- v0.1 ~ v0.3.1 标 ✅; v0.4+ 仍 planned
- 跟 git tag (`v0.3.1`) / runtime_state.json (`current_version: v0.3.1`) 一致
